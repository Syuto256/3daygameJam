// ===============================================================
// Imata シーン構築 DSL
//   Tools > Scene DSL > Build Imata Scene（Ctrl + Alt + G）で Imata シーンへ反映する
//
// 決めごと:
//   - 組み立て先は Assets/Scenes/Imata.unity だけ（他のシーンには反映されない）
//   - 既存シーンを開いたまま、ここに書いた名前のオブジェクトだけを作り直す
//     （手で置いたオブジェクトは残る）
//   - シーンのオブジェクトはすべて最上位の InGame の下にまとめる
//     （InGame は組み立て時に自動で用意されるので、DSL には書かない。Parent: InGame で参照する）
//   - もう作らなくなったオブジェクトは Object ブロックの外に "Remove: 名前" と書くと消える
//   - 手で置いた既存オブジェクトの値を変えたいときは Type: Existing を使う
//     （Parent を省略すると、シーン全体から同じ名前のオブジェクトを探して値だけ上書きする。
//       Existing の名前は削除の対象にならない）
//   - Component は名前空間まで書く（短い名前は Unity 内部の型と衝突することがある）
//
// 書き方:
//   Object
//   {
//       Name: 名前
//       Parent: 親の名前          // 省略するとシーンのルート
//       Type: Empty / Image / TMP_Text / Button / Canvas / プレハブ名 / Existing
//       Component: 型名
//       {
//           フィールド名: 値       // 数値 / true / #RRGGBB / 1,2,3 / @オブジェクト名 / <Sprite>画像名
//       }
//   }
// ===============================================================

// 以前の置き場。InGame の下へ直接置くようにしたので消す
Remove: ImataVisual
